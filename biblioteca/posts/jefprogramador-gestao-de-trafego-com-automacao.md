### Transcrição do vídeo

Subir campanha lá pelo gerenciador de anúncios, isso não existe mais. Não existe mais. Quem faz isso tá perdendo muito tempo, tá jogando a hora no lixo. Hoje é importante aprender somente a subir as campanhas de forma manualmente, mas em um processo onde nós queremos, de fato, trabalhar com o volume pra conseguir ter muitos testes, nós colocamos as automações pra subir as campanhas. Por exemplo, quando você quer validar criativo, trocar a cor, trocar a headline, trocar as imagens, imagina fazer um teste com 20, 30, 40 criativos que é o que nós precisamos para entender quais são aqueles que estão, de fato, levando para um bom resultado. Se você for ter um editor para poder fazer todos esses criativos, se você ter um gestor para subir todos esses criativos, um copywriter para fazer a descrição, para fazer a headline, cara, dá muito trabalho. O que a gente faz é colocar as automações para fazer todos esses processos. Teste A, B, C, D até Z, mil vezes, vai fazer sozinho. É muito mais fácil do que parece. E se você quer entender como construir esse tipo de automação na prática, clica no botão aqui e se cadastre para um evento incrível sobre automações para tráfego pago.
