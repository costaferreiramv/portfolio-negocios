## Resumo

Reel sobre um recurso que troca documentação escrita por demonstração: em vez de escrever o
passo a passo de uma tarefa para virar skill, você grava a tela executando a tarefa uma vez,
falando em voz alta o raciocínio, e a skill é gerada a partir disso.

O autor testou com uma rotina semanal — subir aula para o YouTube — e o resultado é que uma
tarefa de vários minutos virou um pedido de uma frase. Ele também nota que a OpenAI lançou
algo parecido antes, com o mesmo exemplo de demonstração.

## Pontos-chave

- Antes: para criar skill, escrever todo o passo a passo em texto, detalhando cada execução.
- Agora: gravar a tela fazendo a tarefa uma vez; a skill é criada a partir da gravação.
- Falar em voz alta o que está fazendo **e por quê** melhora o resultado.
- Onde fica: no aplicativo de desktop, ícone de "+" → opção de gravar skill.
- Caso testado: subir aula para o YouTube (abrir a pasta, entrar no Studio, preencher nome e
  descrição). Feito uma vez; depois virou pedido de uma frase.
- Candidatos naturais: resposta padrão a cliente, planilha preenchida toda semana, post
  publicado sempre do mesmo jeito.
- Contexto de mercado: a OpenAI lançou recurso equivalente antes, com o mesmo exemplo de
  upload para YouTube — a corrida para acabar com documentação manual começou.

### Transcrição do vídeo

O Claude acabou de lançar algo que eu já esperava. Depois do Codex lançar o [recurso de
gravação] que vocês já viram, agora chegou a versão do Claude chamada Record a Skill. Isso
aqui, gente, muda como que você ensina uma tarefa para o Claude. Antes você escrevia tudo em
texto, o passo a passo, né, para aquela habilidade, explicando cada detalhe de cada execução.
Agora você grava a tela fazendo a tarefa uma vez, o Claude aprende sozinho, só de assistir, e
cria essa skill para você. A opção fica dentro do [app de desktop] no seu computador. Você
abre, clica no ícone de mais, aparece a opção de Record a Skill. Você clica em gravar, faz a
tarefa normal. Você pode, se quiser, ir falando em voz alta o que está fazendo e por quê.
Quando você para a gravação, ele assiste tudo de novo, [e a skill fica] pronta para você usar
sempre que precisar, sem você escrever uma linha de instrução. Eu acabei de fazer o teste com
uma tarefa que eu faço toda semana, que é literalmente subir uma aula para o YouTube: abrir a
pasta com a gravação, entrei no YouTube Studio, coloquei o nome e a descrição. Eu fiz isso uma
vez só. Ele pegou essa gravação, criou uma skill sozinho. Agora, toda vez que eu tenho uma
aula nova, eu só peço e ele repete o processo inteiro, sem eu mostrar de novo, sem eu escrever
absolutamente nada. Ele já sabe o que fazer. Uma tarefa que levava alguns bons minutos toda
semana virou um pedido de uma frase. Pensa aqui quanto que isso vale pro seu negócio: uma
resposta padrão pra um cliente, uma planilha que você preenche toda semana, um post que você
sobe sempre do mesmo jeito. Qualquer tarefa que você repete na sua rotina pode virar uma skill
só de você gravar fazendo ela uma vez. Se você explicar o raciocínio por trás de cada escolha,
melhor ainda.

## Aplicação

**Resolve a parte mais chata do que já é feito aqui.** A operação já tem várias skills
escritas à mão (`fotos-kenlo`, `atualizar-canalpro`, `verificar-imoveis-kenlo`,
`anuncios-meta-andromeda`, `definir-icp-imovel`) — e escrever cada uma custou tempo.

**Rotinas do Portfólio Negócios que são candidatas naturais:**
- Publicar imóvel no site (extrair do Kenlo, escolher capa, gerar markdown, build, push).
  Já existe skill, mas há passos manuais que a gravação capturaria melhor que a descrição.
- Giro quinzenal de anúncios no Canal Pro — fluxo de cliques repetitivo, difícil de
  descrever em texto e fácil de demonstrar.
- Subir carrossel agendado no Instagram.
- Atualizar o registro confidencial de imóveis a cada captação nova.

**O detalhe que mais importa:** falar em voz alta **o porquê** de cada escolha. É
exatamente isso que falta nas skills escritas — elas descrevem o passo, não o critério.
"Escolhi essa foto como capa porque mostra a área de lazer, e capa nunca é fachada" é a
informação que faz a skill acertar sozinha depois.

**Cuidado de segurança:** gravação de tela captura o que está visível — inclusive Kenlo
logado, painel do Canal Pro, dados de proprietário e matrícula. Nunca gravar tela com
registro confidencial aberto, e revisar a skill gerada antes de salvar.

**Ressalva:** o recurso e o local do menu mudam entre versões. Vale conferir na
documentação oficial antes de contar com ele.
