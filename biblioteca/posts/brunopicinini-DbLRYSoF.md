## Legenda

Se você usa Claude Code, estas dicas vão mudar sua rotina.

No carrossel acima separei as 8 mais impactantes. Gravei um vídeo com 24 no total, e as outras 16 estão aqui:

Múltiplas abas: Use iTerm (Mac) ou Windows Terminal com cada agente rodando em uma aba.

Status da aba: Use a extensão "Claude Code iTerm Tab Status" para não se perder com 4 abas ativas.

Status line customizada: Repo, branch, modelo e tokens numa linha. Saiba onde está antes de comandar.

Mobile Simulator: Teste responsivo sem os bugs do inspetor do Chrome. Mais rápido e confiável.

Silenciar debugger: Um atalho de uma linha resolve as notificações que pipocam no Chrome em testes.

/branch: Cria uma conversa nova sem perder a original, permitindo rodar ambas em paralelo em abas separadas.

Effort X High: Modo onde ele decide abrir múltiplos agentes para acelerar. Só monitore os tokens, ele é guloso.

/handoff: Gera um resumo em markdown antes do contexto zerar. Mais direto que o /compact para o próximo round.

Prompt de sistema objetivo: "Seja conciso, sacrifique gramática por objetividade" reduz a carga cognitiva com vários agentes.

Modelos baratos: Use Haiku e Sonnet para tarefas triviais. Economize contexto quando a qualidade máxima não for crucial.

Prompt de estrutura: Peça resumo antes das decisões e opções numeradas no fim. Pare de vasculhar texto para responder.

Remote Control: Controle sessões do terminal pelo celular. Combine com a dica 1 (Amphetamine) para trabalhar na rua.

Claude Code Web: Comece no navegador, vá para o celular e use o comando "teleporte" para trazer de volta ao terminal.

APIs na Web: Configure acesso direto a ClickUp, GitHub e Vercel no Claude Code Web para compensar a falta de MCP nativo.

Diretrizes do Karpathy: As 4 primeiras regras (pensar antes de programar até execução focada) já mudam o jogo. Busque no Google.
