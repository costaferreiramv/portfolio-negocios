### Transcrição do vídeo

Aqui estão 5 skills do Cloud que você precisa instalar agora para ficar à frente de 99% das pessoas. Número 1 é a Marketing Skills do Corey Haynes. Ela instala 23 agentes de marketing totalmente gratuitos, que cuidam de auditoria de CEO, copywriting, sequências de e-mail e muito mais. Número 2 é a Stop Slop Skill. Essa skill faz o Cloud humanizar a sua escrita e remover sinais típicos de textos gerados por IA, como travessões longos e frases de preenchimento, para que o texto realmente pareça escrito por uma pessoa. Número 3 é a We, o X-Pro MaxiSkill. Ela oferece ao Cloud um banco de dados integrado com mais de 50 estilos de interface e 99 diretrizes de UX, permitindo que ele crie interfaces com aparências realmente profissionais. Número 4 é a Remotion Skill. Ela permite que o Cloud abra o próprio editor de vídeo e crie vídeos totalmente animados e prontos para produção, a partir de um único prompt de texto. A número 5 é a Context Engineering Skill. Essa skill reduz a quantidade de tokens que o Cloud utiliza em cada resposta, para que você pare de atingir os limites de uso e consiga aproveitar muito mais o Cloud todos os dias.
