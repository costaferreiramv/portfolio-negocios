## Transcrição

O Cloddy acabou de lançar algo que eu já esperava. Depois do Codex lançar o Recording Replay que vocês já viram, agora chegou a versão do Cloddy chamada Recording a Skill. Isso aqui, gente, muda como que você ensina uma tarefa para o Cloddy. Antes você escrevia tudo em texto, o passo a passo, né, para aquela habilidade, explicando cada detalhe de cada execução. Agora você grava a tela fazendo a tarefa uma vez, o Cloddy aprende sozinho, só de assistir, e cria essa skill para você. A opção fica dentro do Cloddy Cowork no aplicativo dentro do seu computador. Você abre o Clodi Cowork, clica no ícone de mais, aparece a opção de Recording Skill. Você clica em gravar, faz a tarefa normal. Você pode, se quiser, ir falando em voz alta o que está fazendo e por quê. Quando você para a gravação, Clodi assiste tudo de novo, pronta para você usar sempre que você precisar, sem você escrever uma linha de instrução. Eu acabei de fazer o teste com uma tarefa que eu faço toda semana, que é literalmente subir uma aula para o YouTube, abrir a pasta com a gravação, entrei no YouTube Studio, coloquei o nome de descrição. Eu fiz isso uma vez só. O Clod pegou essa gravação, criou uma skill sozinho. Agora, toda vez que eu tenho uma aula nova, eu só peço que o Clod repete o processo inteiro sem eu mostrar de novo, sem eu escrever absolutamente nada. Ele já sabe o que fazer.
